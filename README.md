# TaskFlow – DevOps Capstone Project

## Project Overview
TaskFlow is a task management web application developed and deployed as part of my DevOps capstone project. This project demonstrates Docker containerization, CI/CD automation, cloud deployment, and application monitoring.

## Live Application
- **Website:** https://bhavanasutagatti-cyber.github.io/docker-web-application/

## Technologies Used
- HTML and CSS
- Docker
- Docker Compose
- GitHub Actions
- Docker Hub
- GitHub Pages
- Zoho Catalyst (deployment setup)

## Project Features
- Task creation and management
- Task editing and deletion
- Task search and sorting
- Kanban-style task organization
- CSV export
- Task data persistence

## Docker Configuration
The project includes a `Dockerfile` and `docker-compose.yml` for building and running the application in a container.

Docker image: `bhavanadocker2026/taskflow-devops:latest`

## CI/CD Pipeline
GitHub Actions automates the Docker image build and push process when changes are pushed to the main branch.

Pipeline:
1. Push code to GitHub.
2. Build and test the application.
3. Build the Docker image.
4. Push the image to Docker Hub.
5. Deploy the application and verify its availability.
